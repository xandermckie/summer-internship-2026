# Cowork Learning Notes

## Figma Plugin Experiment

**Date:** June 1, 2026

### What I tried
Installed the Figma design generation plugin and asked it to create a Formula One website mockup.

### What happened
The plugin generated a design, but it was basic and very similar to another Formula One site Claude had already created for me. Minimal prompt resulted in minimal, generic output.

### Key learning
- **Prompt matters.** Vague instructions → generic designs. Need specifics (color scheme, layout structure, unique features).
- **LLM design tools have limits.** They're good for fast mockups but tend toward safe, templated solutions. Don't expect novel design without detailed direction.
- **Output reusability.** The plugin saved a design artifact in Figma, which is useful for iteration, but the baseline was uninspired.

### When to use this
End-of-internship project presentation. Could be valuable for quick mockups or demos, but requires:
- Clear design constraints upfront
- Specific layout/style direction
- Willingness to iterate and refine

### Next steps
- If using Figma plugin again: provide detailed design brief (colors, layout, unique sections)
- Consider it a starting point, not final output
- Pair with manual design refinement for better results

## Chat vs Cowork Decision Matrix

When to use each:

1. **"I need to understand why my Python script is throwing a KeyError."** → **Chat**
   - One-off question, no files to manage, just explanation needed

2. **"I want Claude to go through the 10 files in a folder and rename them all with a consistent naming convention."** → **Cowork**
   - File system operations, batch work, persistent result

3. **"I need to explain a concept from the Carnegie book to prepare for my discussion with Matt."** → **Chat**
   - Conversational, learning, one-time prep

4. **"I want Claude to pull my notes from a Google Doc and format them into a clean study guide."** → **Cowork + connector**
   - External tool access (Google Docs), persistent output file

5. **"I want to run the same code review process on every file I write this summer."** → **Cowork + custom skill**
   - Repeating task, needs consistent behavior, worth automating as a reusable skill
