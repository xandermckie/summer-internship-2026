# Tool Guide: Claude Chat vs Cowork

## Claude Chat

**What is it best for?**
Chat is best for explanations and simple tasks that don't need control of multiple files or much context.

**What's the one setup step that makes it 10x more useful?**
Having a universal prompt so it already knows how you want it to respond and with what context.

**What's a mistake you'd make if you didn't know what you know now?**
Probably not writing strong enough prompts and expecting it to be able to handle multiple files within an entire project.

---

## Claude Cowork

**What makes it fundamentally different from Chat?**
It has access to your files and computer and can make changes autonomously.

**What's the most important setup step and why?**
Having a global instruction, connecting it to a specific repo/folder so that your work is being saved where you need it most.

**What's a Skill, and why would you build a custom one?**
A skill is a simple script or set of instructions for Claude. You would build a custom one to give specific instructions based on what you need Claude to help you complete.

**What's the difference between a Plugin and a Connector?**
A plugin gives Claude the ability to make changes and build things from scratch within a specific service like Figma or a smaller specific application. Connectors give access to accounts and directories from a third party source so that Claude can access things like your Gmail or Drive.

**When would you use Computer Use — and when would you not?**
I would use computer use when I am aware of what task I am trying to accomplish and am able to keep an eye on what Claude is doing. I would not use it when I have my bank information or other sensitive info easily accessible and don't need Claude to complete tasks for me on my PC or laptop.
